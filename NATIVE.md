# B-line — Native (Capacitor)

The native iOS + Android apps are **this same web app** wrapped with [Capacitor](https://capacitorjs.com). One codebase, one repo — every web change is the native app after a sync. No separate UI to maintain.

- **App id:** `com.blineatlanta.app` · **name:** B-line · **web dir:** `dist`
- **iOS** uses **Swift Package Manager** (Capacitor 8) — no CocoaPods needed.
- Platforms live in `ios/` and `android/` (committed). Build outputs + the synced
  `dist` copies are git-ignored and regenerated by `cap sync`.

## Build & run

```bash
# iOS (needs Xcode) — builds web, syncs, and opens the Xcode project.
npm run ios

# Or open ios/App/App.xcodeproj manually after npm run sync.
# Select the App scheme, then run on an iOS 15+ simulator or a provisioned device.

# Android (needs Android Studio + SDK + JDK 17) — builds web, syncs, opens Android Studio.
npm run android

# just re-copy the latest web build into both native shells:
npm run sync
```

`npm run ios` / `android` = `vite build` → `cap sync` → open the native IDE. The committed Xcode shell is `ios/App/App.xcodeproj`; the current web bundle is regenerated in `ios/App/App/public/` during each sync and is intentionally excluded from Git.

## Machine requirements

| Target | Needs | This Mac |
|---|---|---|
| iOS | Xcode | ✅ Xcode 26.3 (SPM — no CocoaPods) |
| Android | Android Studio + SDK + **JDK 17+** | ⚠️ has JDK 8 only + no SDK — install to build |

## How it fits together

- `capacitor.config.ts` points Capacitor at the Vite `dist/` output.
- The React app runs in a native webview; MapLibre tiles, images, and the
  Supabase bug-bin all work over the device network as on web.
- Add native power when wanted via Capacitor plugins (e.g.
  `@capacitor/geolocation` for real trail GPS, `@capacitor/push-notifications`).
  Install the plugin, then `npm run sync`.

## Shared backend

Same Supabase project as the web app (`bline-` tagged bug reports). Web deploys
via Vercel; native ships through the App Store / Play Store from the same source.
